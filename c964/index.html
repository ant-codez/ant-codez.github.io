Profanity filter

A machine-learning text classifier that decides whether a phrase is offensive. Type below: the trained model runs right here in your browser.

How it works

Text is split into words, common English stop words are dropped, and the word counts go to a naive Bayes model trained on 148,758 labeled comments, which decides whether the text is offensive.

The notebook also trains a second model that guesses the kind of offense. It learned from only about 1,600 labeled terms and is right 61% of the time on 320 held-out terms, so this demo leaves it out.

The original project is a Jupyter notebook in Python with scikit-learn. For this page I exported the trained models to JSON and wrote the prediction step in JavaScript. On 5,000 held-out comments, it gives the same answer as scikit-learn every time.
