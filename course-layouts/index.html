Course Layouts

A web map editor for designing the courses of my Roblox game. It draws every course from the game's own build code, and I sketch changes right on the map. Each mark becomes exact coordinates that the AI agents building the course work from.

Why I built it: faster design rounds

The AI agents that build the courses need precise directions. Describing a change in words ("widen the second bend, put a hook over the gap") left room to guess wrong, and every wrong guess cost another round of checking and correcting. Course Layouts turns a sketch into exact coordinates, so the change lands where I drew it.

🎯

Point at a change instead of explaining it

Every mark is saved in the course's own terms: which section, how far along, how far left or right, and how high. A change arrives exact, so there's no back-and-forth about which bend or which jump I meant.

🧭

Always the real course

Each layout is drawn with the same geometry code that builds the course in the game: its floor strips, walls, banks, jumps, drops and shortcuts. I don't have to open Studio and fly around to find a spot, and the map can't drift from what players ride.

⏱️

Read the pacing without a playtest

A side view shows the whole drop, and every jump, drop, shortcut and letter is listed with the time a rider reaches it at par. A slow stretch or two features crowding each other shows up on the map before anyone rides it.

✏️

New courses start as sketches

On a blank sheet I lay track at true width and place posts, walls, hooks and letters. The sheet shows the size limits a course has to fit, so a sketch is something the game can build, not just a drawing.

📱

Design from anywhere

It's a web page, so it works on a laptop or a phone. I can review a course and mark it up away from my desk, without Roblox Studio.

🔄

Stays current on its own

After a course change is pushed, its layout is redrawn and the page republished. The page shows the newest version of every course, with the branch and commit it came from.
