fillit

Give it a set of Tetris pieces and it packs them into the smallest square possible, by backtracking through every placement. Build a set below and press Solve: it runs the original C program, compiled to WebAssembly, in your browser.

How it works

    
Each piece is read from a text file of 4×4 blocks and validated: exactly four # cells, all connected. The solver starts with the smallest square that could hold every piece, tries each piece in each position in order, and backs up when a piece no longer fits. If nothing works it grows the square by one and starts again, so the first answer is always the smallest square.

    
This page runs the same C source as the 2020 repository, unchanged. I compiled it to WebAssembly with clang and wrote a small shim that stands in for malloc, read and write. On 122 test inputs it prints exactly what the native build prints. It runs in a background worker, so a big set never freezes the page.
